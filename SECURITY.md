# Security Policy

## Alcance

Este repositorio contiene ejemplos públicos. No debe contener secretos, tokens, credenciales, claves privadas, IPs privadas, nombres internos de nodos ni configuraciones de producción.

## Reportar un problema

Si detectas una exposición accidental de información sensible, no abras un issue público con el secreto. Contacta mediante:

- auri_orion@noralemilenio.com

## Regla de oro

Los ejemplos deben recibir credenciales por mecanismos externos al código, como variables de entorno, gestores de secretos o identidades de máquina.
