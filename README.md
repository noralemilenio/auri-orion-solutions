## 🧭 Cómo usar este repositorio

1. **Lee la guía:** identifica el problema, los requisitos, el coste y las alternativas.
2. **Entra en su carpeta:** consulta archivos, instrucciones y ejemplos disponibles.
3. **Prueba en un entorno seguro:** empieza con datos ficticios, sin credenciales reales.
4. **Comprueba resultados y límites:** no presupongas que una demostración sirve directamente para producción.

## 🔬 Lo que verás en cada proyecto

**Problema → resultado esperado → herramientas → pasos → ejemplo → comprobación → privacidad → coste → límites → alternativas.**

Las guías editoriales viven en [auri-orion-web](https://github.com/noralemilenio/auri-orion-web); aquí mantenemos el código reproducible. Esta separación evita copiar documentación o prometer código que no existe.

## 💡 Temas que estamos explorando

- 🧠 **IA local y modelos pequeños:** decisiones basadas en memoria disponible, privacidad y coste.
- ⚡ **Automatización de tareas reales:** archivos, reuniones, verificaciones y controles.
- 🔐 **Seguridad por defecto:** permisos mínimos, secretos fuera del código, rollback y auditoría.
- 🧪 **Pruebas reproducibles:** comandos, salida esperada, evidencias y fallos conocidos.

Las ideas de trabajo **no son proyectos terminados**.

## 🤝 Principios editoriales

- Utilidad y evidencia por delante del reclamo.
- Preferimos herramientas gratuitas y abiertas, sin ocultar costes ni requisitos.
- Nada de secretos, IP privadas ni detalles internos de infraestructura.
- Las pruebas se describen con su entorno y fecha, sin extrapolar cifras.
- Si algo no funciona o no está verificado, lo decimos.
